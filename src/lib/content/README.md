# src/lib/content/

> L2 | Parent: [../README.md](../README.md)

- `manifest.ts`: Builds the publication catalog and translation map from validated documents.
- `mdx.ts`: Validates supported MDX syntax, headings, references, and component attributes.
- `model.ts`: Serializable content types, stable identities, rendered anchors, and module grouping.
- `scan.ts`: Reads ordered language folders using the compiler's YAML parser, portable paths, and collision checks.
- `schema.ts`: Strict course, lesson, date, and directory metadata schemas.
- `source.ts`: Server-only course, lesson, and compiled article queries through mode-specific generated aliases.
- `validate.ts`: Validates ownership, translations, ordering, and links to rendered destinations.
