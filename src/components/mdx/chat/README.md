# src/components/mdx/chat/

> L2 | Parent: [../README.md](../README.md)

- `chat-message.tsx`: Server-rendered Chat and configurable ChatMessage. The required from prop selects user/assistant alignment and avatars. The state prop defaults to complete for bubbles; assistant state="thinking" shows a plain Spinner and Thinking status. Both states share one message renderer and light gray avatars. Reduced motion stops the spinner. Chat groups rows inside one quote-frame border.
