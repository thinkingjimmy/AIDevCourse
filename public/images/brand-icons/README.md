# public/images/brand-icons/

> L2 | Parent: [../README.md](../README.md)

Five original brand candidates for AIDevCourse. Each PNG is 1254 × 1254 pixels with an alpha channel. The user selected `02-prompt-cursor.png`; its production assets are maintained in [../brand/README.md](../brand/README.md). The generated artwork has not been traced into vector paths.

- `01-code-book.png`: Code brackets and an open book.
- `02-prompt-cursor.png`: A terminal prompt and cursor within a D-shaped mark.
- `03-learning-path.png`: An A-shaped mark with ascending steps.
- `04-open-chip.png`: An open book within a processor chip.
- `05-adc-monogram.png`: Interlocking A, D, and C letter shapes.
- [preview.html](./preview.html): Responsive comparison with the site wordmark, 16–48 px examples, and PNG downloads. The page is marked noindex.
- [prompts.md](./prompts.md): Exact prompts and built-in generation settings.
- `README.md`: Asset map and usage notes.

Open `/images/brand-icons/preview.html` through the site server or open the local HTML file to review the original candidates.
