## What you can do by the end

Complete a small AI-assisted coding task with useful context, clear constraints, a real check, and a safety review.

## How to read this

Read the six modules in order. A lesson marked Draft already has a title and a two-sentence summary; the body comes later. The exercises in the finished lessons are worth doing.

## What each module is for

### Understand AI models

See what a model is actually doing before you decide what it is good at.

### Choose and connect a model

Pick a model for this task, and tell a subscription, an API key, cloud, and local apart.

### Prompts, rules, and context

Turn one request into a prompt you can carry out, and pin the scope with rules and context.

### Agents and tools

See how an agent loops through tools, and what permissions, skills, and MCP each control.

### Check the result

Use small steps, reading, and tests to confirm the generated change actually finished the task.

### Use AI safely

Make hallucination, data, and generated-code risk part of every session.
