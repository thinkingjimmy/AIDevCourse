We have learned that [models can request tool calls](/courses/llm-101/what-is-a-tool), and AI Chat can help us [create and modify interactive content](/courses/deepseek-101/ai-chat-tips).

These are Chat product features. What, then, is the popular idea of an Agent, and how does it differ from Chat?

## 1. What is an Agent?

An <JimmyNoteAnchor id="001">Agent</JimmyNoteAnchor> is often described as an intelligent agent or a proxy.

<JimmyNote anchor="001">
    The industry has many definitions of Agent. Because the topic can be complex, this lesson focuses on the core concept. We will cover the details in [Agent 101 (简体中文)](/zh/courses/agent-101).
</JimmyNote>

Earlier, we saw that a Chat model receives input from the server program, performs calculations, and generates an answer. The server program returns the answer to Chat, which displays it to you.

An Agent works a little differently. Its program first asks the model to consider what to do. It then calls a tool to act, observes the result, and considers the next step.

This cycle—“think” → “act” → “observe” → “think” → “act” → “observe”—repeats until the task is complete.

## 2. How does a model move from answering to thinking and acting?

Let us use a concrete example to understand that shift.

Assume the model’s training data contains no information about Inception or The Matrix. The user asks: What is the sum of the birth year of Inception’s director and the release year of the first Matrix film?

The Agent program sends a message to the server program. After processing it, the server returns data with this structure.

```json
{
  "messages": [
    {
      "role": "user", // Message role: user
      "content": "What is the sum of the birth year of Inception’s director and the release year of the first Matrix film?" // The user’s question
    },
    {
      "role": "assistant", // Message role: model
      "reasoning": "To calculate the sum, I need two unknown values: the birth year of Inception’s director and the release year of the first Matrix film. First, find Inception’s director.", // The model’s reasoning
      "content": null, // Generated content: empty. The model requested a tool call instead of answering.
      "tool_calls": [
        {
          "type": "function",
          "function": {
            "name": "search_web",
            "arguments": "{\"query\":\"Inception movie director\"}" // Search for Inception’s director 
          }
        }
      ]
    },
    {
      "role": "tool", // Message role: tool
      "content": "Inception is a science-fiction action film released in 2010, written and directed by Christopher Nolan." // Result returned by the tool
    }
  ]
}
```

Compare this with the earlier example. There is an extra `reasoning` field that shows the model’s reasoning process. This is the “think” step:

```json
{
  "reasoning": "To calculate the sum, I need two unknown values: the birth year of Inception’s director and the release year of the first Matrix film. First, find Inception’s director.", // The model’s reasoning
}
```

From that reasoning, the model generates a request to search for “Inception movie director”. This is the “act” step:

```json
{
  "tool_calls": [
        {
          "type": "function",
          "function": {
            "name": "search_web",
            "arguments": "{\"query\":\"Inception movie director\"}" // Search for Inception’s director 
          }
        }
      ]
}
```

The tool returns a search result, and the model performs the “observe” step:

```json
{
  {
    "role": "tool", // Message role: tool
    "content": "Inception is a science-fiction action film released in 2010, written and directed by Christopher Nolan." // Result returned by the tool
  }
}
```



The JSON shows that the tool returned the director’s name, Christopher Nolan, but not his birth year. The model therefore reasons and calls a tool again—a second round of thinking, acting, and observing—and gets this result:

      "content": null, // Generated content: empty. The model requested a tool call instead of answering.
      "tool_calls": [
        {
          "type": "function",
          "function": {
            "name": "search_web",
            "arguments": "{\"query\":\"Inception movie director\"}"
          }
        }
      ]
    },
    {
      "role": "tool", // Message role: tool
      "content": "Inception is a science-fiction action film released in 2010, written and directed by Christopher Nolan." // Result returned by the tool
    }
    # Second reasoning step and tool call
    {
      "role": "assistant", // Message role: model
      "reasoning": "The director is Christopher Nolan. I still need his birth year and The Matrix’s release year. Next, find Christopher Nolan’s birth year.", // The model’s reasoning

## 3. Why use this pattern?

The repeated “think” → “act” → “observe” cycle is also called [ReAct](https://react-lm.github.io/). It is the core working principle of an Agent and the main difference from traditional AI Chat.

Why does this pattern exist?

In some cases, running AI Chat only once does not give the language model enough information to answer. In the example above, still assuming it knows nothing about Inception or The Matrix, Chat might give this <JimmyNoteAnchor id="002">answer</JimmyNoteAnchor>:

<Chat>
<ChatMessage from="user">
What is the sum of the birth year of Inception’s director and the release year of the first Matrix film?
</ChatMessage>

<ChatMessage from="assistant">
<ChatToolCall name="search_web" title="Search the web" defaultOpen={true}>
**Call arguments**

```json
{
  "query": "Inception movie director"
}
```

**Returned result**

```json
{
  "director": "Christopher Nolan"
}
```
</ChatToolCall>

Sorry, I only know that Inception’s director is Christopher Nolan. I do not know his birth year.
</ChatMessage>
</Chat>

<JimmyNote anchor="002">
    You may feel this is an unsuitable example: models have learned from so much data, so why would they not know? Indeed, a Chat product might answer this particular question correctly.
    
    I use this example to explain the Agent principle and show how tools and ReAct can help a model solve unfamiliar problems autonomously. Training usually takes a long time, so a model’s knowledge often lags by several months, or even half a year.
</JimmyNote>
