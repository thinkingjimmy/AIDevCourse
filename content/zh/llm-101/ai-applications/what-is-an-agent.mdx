前面我们已经知道，[模型可以请求调用工具](/zh/courses/llm-101/what-is-a-tool)，AI Chat 也可以帮我们[生成和修改交互内容](/zh/courses/deepseek-101/ai-chat-tips)。

这些都是 Chat 产品的功能，现在流行的所谓的智能体（Agent）又是什么？它和 Chat 有什么区别？

## 一、Agent 是什么？

<JimmyNoteAnchor id="001">Agent</JimmyNoteAnchor> 常被译为「智能体」或「代理」。

<JimmyNote anchor="001">
    目前业界有很多关于 Agent 的定义，考虑到 Agent 相关的知识相对比较复杂，所以本章节仅会重点讲其最核心的概念。其余细节会在 [Agent 101](/zh/courses/agent-101) 课程中详细讲解。
</JimmyNote>

前面的课程中我们提到，当用户使用 Chat 产品的时候，模型程序接收到服务器程序的输入后，会进行一系列的计算，然后生成回答。最后，服务器程序将回答传回给 Chat 程序，Chat 程序再将其展示给你。

而 Agent 则稍微有点区别，Agent 程序会先让模型思考当前应该做什么，然后获得结果后，调用工具行动，再观察工具返回的结果，并继续思考下一步。

这个「想」 → 「做」 → 「看」 → 「想」 → 「做」 → 「看」 → …… 的过程，会一直重复，直到任务完成。

## 二、模型怎么从「回答」变成「能想」和「能做」？

我们将通过一个具体的例子，来理解模型怎么从「回答」变成「能想」和「能做」。

假设模型的训练数据里没有任何《盗梦空间》和《黑客帝国》的信息，然后用户问模型：电影《盗梦空间》（Inception）导演的出生年份，加上《黑客帝国》（The Matrix）第一部的上映年份，总和是多少？

Agent 程序发送消息到服务器程序后，经过一系列运算，会返回如下结构的数据。

```json
{
  "messages": [
    {
      "role": "user", // 消息身份：用户
      "content": "电影《盗梦空间》（Inception）导演的出生年份，加上《黑客帝国》（The Matrix）第一部的上映年份，总和是多少？" // 用户的问题内容
    },
    {
      "role": "assistant", // 消息身份：模型
      "reasoning": "要算出总和，我需要先知道两个未知数：《盗梦空间》导演是谁及其出生年份，以及《黑客帝国》第一部的上映年份。先查《盗梦空间》的导演。", // 模型的思考过程
      "content": null, // 模型生成的内容：空。因为没有回答，而是直接生成了工具调用请求。
      "tool_calls": [
        {
          "type": "function",
          "function": {
            "name": "search_web",
            "arguments": "{\"query\":\"Inception movie director\"}" // 搜索盗梦空间导演 
          }
        }
      ]
    },
    {
      "role": "tool", // 消息身份：工具
      "content": "《盗梦空间》（Inception）是 2010 年上映的科幻动作片，由克里斯托弗·诺兰（Christopher Nolan）编剧并执导。" // 工具返回的结果
    }
  ]
}
```

可以细看对比一下和之前的区别，多了一个 `reasoning` 字段，这个字段里显示的就是模型思考的过程。这一步就是前面提到的 「想」:

```json
{
  "reasoning": "要算出总和，我需要先知道两个未知数：《盗梦空间》导演是谁及其出生年份，以及《黑客帝国》第一部的上映年份。先查《盗梦空间》的导演。", // 模型的思考过程
}
```

有了这个思考后，模型会根据这个思考，生成一个搜索工具请求，搜索「盗梦空间的导演」，这一步就是前面提到的 「做」:

```json
{
  "tool_calls": [
        {
          "type": "function",
          "function": {
            "name": "search_web",
            "arguments": "{\"query\":\"Inception movie director\"}" // 搜索盗梦空间导演 
          }
        }
      ]
}
```

工具会返回搜索结果，然后模型会进行「看」：

```json
{
  {
    "role": "tool", // 消息身份：工具
    "content": "《盗梦空间》（Inception）是 2010 年上映的科幻动作片，由克里斯托弗·诺兰（Christopher Nolan）编剧并执导。" // 工具返回的结果
  }
}
```

## 三、为何有这种模式？

上述的这个过程「想」 → 「做」 → 「看」 → 「想」 → 「做」 → 「看」 → …… 的过程，又被称为 [ReAct](https://react-lm.github.io/)。这就是 Agent 的核心工作原理，它也是和传统的 AI Chat 最大的区别。

为何会有这种使用模式？

原因是 AI Chat 在某些情况下，仅运行一次，并不足以让大语言模型答出答案。如果上述的例子（还是假设大语言模型不知道什么是《盗梦空间》和《黑客帝国》），在 AI Chat 里提问，可能获得的<JimmyNoteAnchor id="002">答案</JimmyNoteAnchor>将会是：

<Chat>
<ChatMessage from="user">
电影《盗梦空间》（Inception）导演的出生年份，加上《黑客帝国》（The Matrix）第一部的上映年份，总和是多少？
</ChatMessage>

<ChatMessage from="assistant">
<ChatToolCall name="search_web" title="搜索网页" defaultOpen={true}>
**调用参数**

```json
{
  "query": "Inception movie director"
}
```

**返回结果**

```json
{
  "director": "Christopher Nolan"
}
```
</ChatToolCall>

抱歉，我仅知道《盗梦空间》的导演是 Christopher Nolan，但不知道他的出生年份。
</ChatMessage>
</Chat>

<JimmyNote anchor="002">
    你可能会觉得这个例子有点不合适，因为大语言模型训练的语料里已经包含了大量的数据，怎么会无法回答呢？的确这个案例如果你直接使用 chat 产品，或许也能得到正确的结果。
    
    我举这个例子，更多的是让大家理解 Agent 的原理，同时告知大家模型是如何通过工具和 ReAct 自主地解决一些它没接触过的问题。毕竟一般情况下，模型的训练都需要很长的时间，其知识一般会落后几个月，甚至半年。
</JimmyNote>
