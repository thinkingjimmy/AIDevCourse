<KeyTakeaway>
Chat 是一问一答；Harness 是一个能读写文件、执行任务、按计划干活的 Agent 工作台。能力更大，也意味着你更要会管。
</KeyTakeaway>

## 一、DeepSeek Harness 是什么

DeepSeek Harness 是 DeepSeek 开源的 Agent 工具，目前是预览版，面向全球开放测试。官方对它的定位很直接：**开箱即用**，日常办公、写代码、构建自己的 Harness 都可以从它开始。

「harness」原本是挽具的意思，在这里可以理解成「把模型装进一个能真正执行任务的框架」：模型不再只是回一段文字，而是可以读文件、改代码、运行命令、安装插件，把一件事连续做完。

它有两种打开方式：

- **桌面端**：从[官方页面](https://www.deepseek.com/harness/)下载 macOS（Apple 芯片）或 Windows（64 位）版本。
- **网页版**：安装 Node.js 后，用 `npx @deepseek-ai/dsh web` 启动 Web UI。

源码和插件生态都在 [GitHub](https://github.com/deepseek-ai/deepseek-harness) 上，采用 MIT 许可。

## 二、它和 DeepSeek Chat 有什么不同

| | DeepSeek Chat | DeepSeek Harness |
| --- | --- | --- |
| 交互方式 | 在对话框里一问一答 | 给它一个目标，它连续执行多步 |
| 能碰到什么 | 你贴进去的文字和文件 | 工作区里的文件、命令、插件、后台任务 |
| 结果在哪 | 聊天记录里 | 工作区的文件改动、执行轨迹里 |
| 风险 | 说错话 | 可能真的改文件、跑命令 |

所以，Harness 更像「把活交给一个会用电脑的助手」，而不是「问一个更聪明的聊天窗口」。

## 三、它能做什么

官方把能力分成五块，你可以对照自己的需求判断要不要用：

1. **日常工作**：整理资料、分析表格、写文档、做汇报。任务成果可以在对话里直接预览，再继续修改。
2. **写代码、改仓库**：理解项目结构、修问题、加功能、跑测试。
3. **查资料、核对信息**：搜索、交叉查证，并给出来源。
4. **处理耗时任务**：运行脚本、批量处理文件，在后台执行，随时查看进度。
5. **安装插件、扩展能力**：使用现有插件，也可以在「创造模式」里通过对话创建自己的插件。

另外，它支持**自动化任务**：比如设定「每周五整理本周记录、生成周报」，到点自动执行。

## 四、第一次打开，先认识这几个地方

不同版本界面会有差异，但结构大致相同：

- **新会话**：一个任务通常从一个新会话开始，上下文越干净，Agent 越不容易被之前的内容带偏。
- **工作区**：Agent 只能在工作区里读写文件。先确认工作区指向你允许它动的文件夹。
- **插件**：官方和社区插件都在这里安装。装之前看清楚它需要什么权限。
- **自动化任务**：定时任务的入口，适合规律性的重复工作。
- **开发者工具**：能看到每一轮的执行轨迹、调用了哪些工具、花了多少时间。这是判断它「有没有真做完」的关键。

## 五、能力越大，越要守住边界

Harness 会真的改你的文件、执行命令、安装插件。第一次用时，建议先做到下面几点：

- **先备份，或用 Git**：在一个可以回滚的目录里练习，改动不对就还原。
- **从最小工作区开始**：只给它一个测试文件夹，不要一上来就指向整个硬盘或重要项目。
- **先看计划再放行**：让它先说打算怎么做，再决定是否继续。
- **用执行轨迹和 diff 验收**：不要只看它的总结，看它实际改了哪些文件、运行了什么命令。
- **敏感资料不进工作区**：密钥、账号、客户数据都不应该交给它处理。
- **危险操作先问人**：删除、批量替换、发布之类的动作，保持人工确认。

如果你对 Agent 的执行循环、权限和停止条件还不熟，建议先读 [Agent 101](/zh/courses/agent-101/about-this-course)；工具调用和上下文的基础在 [LLM 101 的「什么是工具？」](/zh/courses/llm-101/what-is-a-tool)。

## 六、动手试一试

1. 下载桌面端，或用 `npx @deepseek-ai/dsh web` 启动网页版。
2. 新建一个空文件夹作为工作区，问它「你能做什么，需要我提供什么」。
3. 放进去两三个文本文件，让它整理成一份摘要；做完后检查执行轨迹和文件改动。
4. 再给它一个多步骤的小任务，比如「读取文件 → 改一处措辞 → 输出 diff」，观察它怎么拆步骤。
5. 最后对比一下：同一件事，用 Chat 和用 Harness 分别要花多少时间、你要检查多少东西。

课程后面会继续补充更具体的用法：插件怎么装、自动化任务怎么写、代码任务怎么验收。这一节先建立整体印象就够了。
