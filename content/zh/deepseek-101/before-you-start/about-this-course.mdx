## 一、为什么要单独学 DeepSeek？

其实本课程里教的内容，很多并不是只能在 DeepSeek 上使用，你也可以在 ChatGPT 或 Claude ，以及其他大语言模型聊天工具上使用。

只是说因为 DeepSeek 开源且费用相对便宜，比较适合各位用来学习，所以我才单独开一门课来讲讲。

## 二、这门课教什么？

这门课主要教两个方向的内容：

- 如何使用 DeepSeek Chat：虽然 Chat 产品比较简单，但也会有一些 prompt 相关的技巧。某些技巧能极大地提高模型回答的质量。即使你在 Chat 里而是在 Agent 里使用，也会有益处，所以建议你先快速看完。
- 如何使用 DeepSeek Harness（或者说是 DeepSeek 的 Agent 模式）：我会通过几个案例来介绍一下如何将其用到日常生活和工作当中，以及如何使用 DeepSeek Harness 来构建插件。

## 三、怎么学？

这门课程比较偏实践，所以不太需要特别多理论的了解，所以我建议你边看教程，边打开 DeepSeek 并进行实践。我认为练比看更重要。
