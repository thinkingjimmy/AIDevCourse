これらは Chat 製品の機能です。では、最近よく聞く Agent（エージェント）とは何で、Chat とどう違うのでしょうか？

## 1. Agent とは何か？

<JimmyNoteAnchor id="001">Agent</JimmyNoteAnchor> は、知的エージェントや代理として説明されます。

<JimmyNote anchor="001">
    業界には Agent の定義がいくつもあります。複雑な話題なので、この授業では中心となる概念に絞ります。詳しい内容は [Agent 101（简体中文）](/zh/courses/agent-101) で扱います。
</JimmyNote>

前の授業では、Chat のモデルがサーバープログラムから入力を受け取り、計算して回答を生成すると説明しました。その回答をサーバーが Chat プログラムに返し、ユーザーに表示します。

Agent は少し違います。まずモデルに今何をするべきかを考えさせます。その結果に応じてツールで行動し、返された結果を観察して、次の一手を考えます。

この「考える」→「行動する」→「観察する」→「考える」→「行動する」→「観察する」という流れを、仕事が終わるまで繰り返します。

## 2. モデルはどうやって回答から思考と行動へ進むのか？

具体的な例で、この変化を見ていきましょう。

モデルの学習データに映画『インセプション』と『マトリックス』の情報がまったくないとします。ユーザーは「『インセプション』の監督の生年と、『マトリックス』第 1 作の公開年を足すと、いくつになりますか？」と聞きます。

Agent プログラムがサーバープログラムへメッセージを送り、処理が行われると、次の構造のデータが返ります。

```json
{
  "messages": [
    {
      "role": "user", // メッセージの役割：ユーザー
      "content": "『インセプション』の監督の生年と、『マトリックス』第 1 作の公開年を足すと、いくつになりますか？" // ユーザーの質問内容
    },
    {
      "role": "assistant", // メッセージの役割：モデル
      "reasoning": "合計を出すには、まだわからない 2 つの値が必要です。『インセプション』の監督とその生年、そして『マトリックス』第 1 作の公開年です。まず監督を調べます。", // モデルの思考過程
      "content": null, // 生成内容：空。回答ではなくツール呼び出し要求を生成しています。
      "tool_calls": [
        {
          "type": "function",
          "function": {
            "name": "search_web",
            "arguments": "{\"query\":\"Inception movie director\"}" // 『インセプション』の監督を検索 
          }
        }
      ]
    },
    {
      "role": "tool", // メッセージの役割：ツール
      "content": "『インセプション』（Inception）は 2010 年公開の SF アクション映画で、Christopher Nolan が脚本と監督を担当しています。" // ツールが返した結果
    }
  ]
}
```

前の例と比べると、`reasoning` フィールドが増えています。ここにはモデルの思考過程が示されています。これが「考える」の段階です。

```json
{
  "reasoning": "合計を出すには、まだわからない 2 つの値が必要です。『インセプション』の監督とその生年、そして『マトリックス』第 1 作の公開年です。まず監督を調べます。", // モデルの思考過程
}
```

この思考に基づき、モデルは『インセプション』の監督を探す検索要求を生成します。これが「行動する」の段階です。

```json
{
  "tool_calls": [
        {
          "type": "function",
          "function": {
            "name": "search_web",
            "arguments": "{\"query\":\"Inception movie director\"}" // 『インセプション』の監督を検索 
          }
        }
      ]
}
```

ツールが検索結果を返し、モデルは「観察する」段階に入ります。

```json
{
  {
    "role": "tool", // メッセージの役割：ツール
    "content": "『インセプション』（Inception）は 2010 年公開の SF アクション映画で、Christopher Nolan が脚本と監督を担当しています。" // ツールが返した結果
  }
}
```



JSON では、ツールから監督名の Christopher Nolan が返っていますが、生年はありません。そこでモデルはもう一度考えてツールを呼び出し、2 回目の「考える・行動する・観察する」を行います。

## 3. なぜこの方式を使うのか？

「考える」→「行動する」→「観察する」を繰り返す流れは、[ReAct](https://react-lm.github.io/) とも呼ばれます。これが Agent の中心的な仕組みであり、従来の AI Chat との大きな違いです。

なぜこのような使い方があるのでしょうか？

AI Chat を 1 回実行するだけでは、答えるための情報が足りない場合があるからです。先ほどと同じく、モデルが『インセプション』と『マトリックス』を知らないとすると、Chat の<JimmyNoteAnchor id="002">回答</JimmyNoteAnchor>は次のようになるかもしれません。

<Chat>
<ChatMessage from="user">
『インセプション』の監督の生年と、『マトリックス』第 1 作の公開年を足すと、いくつになりますか？
</ChatMessage>

<ChatMessage from="assistant">
<ChatToolCall name="search_web" title="ウェブ検索" defaultOpen={true}>
**呼び出し引数**

```json
{
  "query": "Inception movie director"
}
```

**返された結果**

```json
{
  "director": "Christopher Nolan"
}
```
</ChatToolCall>

すみません。『インセプション』の監督が Christopher Nolan であることはわかりますが、生年はわかりません。
</ChatMessage>
</Chat>

<JimmyNote anchor="002">
    モデルは大量のデータで学習しているのに答えられないのか、と、この例を不自然に感じるかもしれません。確かに、実際の Chat 製品なら正しく答えられる場合もあります。
    
    この例の目的は Agent の仕組みを理解し、モデルがツールと ReAct を使って未知の問題を自分で解決する流れを知ることです。学習には通常長い時間がかかるので、知識は数か月、場合によっては半年ほど遅れます。
</JimmyNote>
