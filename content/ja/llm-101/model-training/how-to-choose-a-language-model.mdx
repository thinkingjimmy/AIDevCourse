オープンソースモデルのよくある疑問を説明したので、次は自分に合う大規模言語モデルの選び方です。

## Q1：どのモデルが強いかを知るには

まず、強さは相対的です。2026 年 11 月の時点で、すべてにおいて完璧なモデルは見たことがありません。

中国語の文章が得意でも、コードの修正が得意とは限りません。コードが得意なモデルは、料金が高いかもしれません。では、どう比較すればよいのでしょうか。

公開評価には、主に 2 種類あります。

- **ベンチマーク：** 決められた課題をモデルに解かせ、一定の規則で採点します。知識問題、数学、コードの修正などが対象です。特定の課題での性能を比較できます。[DeepSWE](https://deepswe.datacurve.ai/) や [TerminalBench](https://www.tbench.ai/) が例です。Android アプリ開発向けの [Android Bench](https://developer.android.com/bench) のように、分野を絞った評価もあります。自分の課題が明確なら、まず関連する評価を探しましょう。
- **人の好みによる評価：** 同じ質問に複数のモデルが答え、参加者はモデル名を知らずに好きな回答を選びます。参加者の好みは分かりますが、「好まれる」と「事実としてより正確」は別の基準です。たとえば [Arena AI](https://arena.ai/) のフロントエンド評価では、生成した画面の見た目と要望への合い方を比べます。見た目のよさは、比較的主観的です。

どちらも参考情報であり、全面的に頼るべきものではありません。モデルの強さは相対的で、評価の課題が自分の実務と一致するとは限りません。

迷ったら、私のもう 1 つのサイト、[Vibe Coding Navigator](https://vibecodingnav.com) をご覧ください。主なモデルの評価をまとめているので、選ぶ際の参考にできます。

2026 年 11 月時点で、私は次のモデルやツールを選んでいます。

- Grok Bot：リクエストを自動で振り分ける製品で、X の Grok モデルを使う場合も、Claude を使う場合もあります。製品体験がよいので、Personal Agent として選んでいます。Personal Agent は後のレッスンで説明します。
- Claude Code：コーディングには、Opus 5.5 を使う Claude Code を選びます。利用枠を使い切ったら Codex が予備です。ただし、アプリやブラウザーを操作する computer use には、Codex を選びます。
- Gemini：Google のモデルは、コーディングに選ぶほど高く評価していません。ただし、Gemini は文章を書くのがかなり得意です。
- DeepSeek：ほかの中国製モデルと同様、あまり使っていません。より強いモデルを使えて、料金も払えるなら、弱いモデルは選ばないでしょう。

## Q3：ChatGPT や Claude は高い。ほかの選択肢はあるか

モデル料金についての考え方を説明します。以前、X でも共有しました。

<XEmbed url="https://x.com/thinkingjimmy/status/2114977301247209703?a=ovCfeRNkS1z0hf7Dk9E&s=20" />

少し詳しく説明します。

料金表だけでは、実際の利用コストは分かりません。表示価格が安くても、総費用が安いとは限りません。

モデル A が 100 万トークンあたり 1 米ドル、モデル B が 5 米ドルだとします。ある課題に A が 1,000 万トークン、B が 100 万トークンを使うなら、実際には A のほうが高くなります。

問題を修正する時間も、まだ含めていません。A でコードを書き、能力不足でバグが発生して修正に時間がかかれば、お金と時間の両方で B を上回るかもしれません。

多くの提供元にはサブスクリプションもあり、5 時間や 1 週間などの期間ごとに利用上限が決まっています。通常、正確なトークン枠は公開されず、市場の状況に応じて変わることもあります。

2026 年時点では、Claude Code と Codex のサブスクリプションは、依然として最も費用対効果が高い選択です。使えるトークンを API 料金で換算すると、契約料金を大きく上回ります。予算が許せば、節約だけを理由に安いモデルを選ぶより、最上位のモデルのサブスクリプションをおすすめします。

比較的簡単な課題だけに AI を使いたいなら、DeepSeek もよい選択肢です。残念ながらサブスクリプションはなく、必要に応じて API の利用分を購入します。
