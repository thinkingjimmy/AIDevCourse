Nous savons maintenant que [les modèles peuvent demander des appels d’outils](/fr/courses/llm-101/what-is-a-tool) et qu’AI Chat peut nous aider à [créer et modifier des contenus interactifs](/fr/courses/llm-101/ai-chat-tips).

Ce sont des fonctions des produits Chat. Qu’est-ce donc qu’un Agent, cette notion si répandue aujourd’hui ? En quoi diffère-t-il de Chat ?

## 1. Qu’est-ce qu’un Agent ?

Un <JimmyNoteAnchor id="001">Agent</JimmyNoteAnchor> est souvent décrit comme un agent intelligent ou un intermédiaire.

<JimmyNote anchor="001">
    Le secteur propose de nombreuses définitions. Le sujet étant complexe, cette leçon se limite au concept central. Les détails seront abordés dans [Agent 101 (简体中文)](/zh/courses/agent-101).
</JimmyNote>

Nous avons vu qu’un modèle de Chat reçoit l’entrée du programme serveur, effectue des calculs et génère une réponse. Le serveur transmet ensuite cette réponse au programme Chat, qui vous l’affiche.

Un Agent fonctionne un peu différemment. Son programme demande d’abord au modèle de réfléchir à l’action à entreprendre. Il appelle ensuite un outil, observe le résultat et réfléchit à la suite.

Ce cycle « réfléchir » → « agir » → « observer » → « réfléchir » → « agir » → « observer » se répète jusqu’à la fin de la tâche.

## 2. Comment passer de la réponse à la réflexion et à l’action ?

Prenons un exemple concret pour comprendre ce passage.

Supposons que les données d’entraînement ne contiennent rien sur Inception ou Matrix. L’utilisateur demande : quelle est la somme de l’année de naissance du réalisateur d’Inception et de l’année de sortie du premier Matrix ?

Le programme Agent envoie un message au programme serveur. Après traitement, celui-ci renvoie des données de la forme suivante.

```json
{
  "messages": [
    {
      "role": "user", // Rôle du message : utilisateur
      "content": "Quelle est la somme de l’année de naissance du réalisateur d’Inception et de l’année de sortie du premier Matrix ?" // Question de l’utilisateur
    },
    {
      "role": "assistant", // Rôle du message : modèle
      "reasoning": "Pour calculer la somme, il me manque deux valeurs : l’année de naissance du réalisateur d’Inception et l’année de sortie du premier Matrix. Cherchons d’abord le réalisateur d’Inception.", // Raisonnement du modèle
      "content": null, // Contenu généré : vide. Le modèle demande un appel d’outil au lieu de répondre.
      "tool_calls": [
        {
          "type": "function",
          "function": {
            "name": "search_web",
            "arguments": "{\"query\":\"Inception movie director\"}" // Rechercher le réalisateur d’Inception 
          }
        }
      ]
    },
    {
      "role": "tool", // Rôle du message : outil
      "content": "Inception est un film d’action et de science-fiction sorti en 2010, écrit et réalisé par Christopher Nolan." // Résultat renvoyé par l’outil
    }
  ]
}
```

Comparez avec l’exemple précédent. Un champ `reasoning` supplémentaire présente le raisonnement du modèle. C’est l’étape « réfléchir » :

```json
{
  "reasoning": "Pour calculer la somme, il me manque deux valeurs : l’année de naissance du réalisateur d’Inception et l’année de sortie du premier Matrix. Cherchons d’abord le réalisateur d’Inception.", // Raisonnement du modèle
}
```

À partir de ce raisonnement, le modèle génère une demande de recherche sur le réalisateur d’Inception. C’est l’étape « agir » :

```json
{
  "tool_calls": [
        {
          "type": "function",
          "function": {
            "name": "search_web",
            "arguments": "{\"query\":\"Inception movie director\"}" // Rechercher le réalisateur d’Inception 
          }
        }
      ]
}
```

L’outil renvoie le résultat, puis le modèle passe à l’étape « observer » :

```json
{
  {
    "role": "tool", // Rôle du message : outil
    "content": "Inception est un film d’action et de science-fiction sorti en 2010, écrit et réalisé par Christopher Nolan." // Résultat renvoyé par l’outil
  }
}
```



Le JSON montre que l’outil a renvoyé le nom du réalisateur, Christopher Nolan, mais pas son année de naissance. Le modèle réfléchit donc à nouveau et appelle un outil. Ce deuxième cycle de réflexion, d’action et d’observation donne le résultat suivant :

      "tool_calls": [

    {
      "role": "assistant", // Rôle du message : modèle
      "reasoning": "Le réalisateur est Christopher Nolan. Il me manque son année de naissance et l’année de sortie de Matrix. Cherchons maintenant l’année de naissance de Christopher Nolan.", // Raisonnement du modèle

## 3. Pourquoi utiliser ce fonctionnement ?

Le cycle répété « réfléchir » → « agir » → « observer » est aussi appelé [ReAct](https://react-lm.github.io/). C’est le principe central de l’Agent et sa principale différence avec AI Chat traditionnel.

Pourquoi ce mode de fonctionnement existe-t-il ?

Dans certains cas, une seule exécution d’AI Chat ne suffit pas au modèle pour répondre. Dans notre exemple, toujours en supposant qu’il ne connaît ni Inception ni Matrix, Chat pourrait donner cette <JimmyNoteAnchor id="002">réponse</JimmyNoteAnchor> :

<Chat>
<ChatMessage from="user">
Quelle est la somme de l’année de naissance du réalisateur d’Inception et de l’année de sortie du premier Matrix ?
</ChatMessage>

<ChatMessage from="assistant">
<ChatToolCall name="search_web" title="Rechercher sur le web" defaultOpen={true}>
**Arguments de l’appel**

```json
{
  "query": "Inception movie director"
}
```

**Résultat renvoyé**

```json
{
  "director": "Christopher Nolan"
}
```
</ChatToolCall>

Désolé, je sais seulement que le réalisateur d’Inception est Christopher Nolan. Je ne connais pas son année de naissance.
</ChatMessage>
</Chat>

<JimmyNote anchor="002">
    Cet exemple peut vous sembler mal choisi : les modèles ont appris sur tant de données, pourquoi ne sauraient-ils pas répondre ? En effet, un produit Chat pourrait fournir la bonne réponse à cette question précise.
    
    J’utilise surtout cet exemple pour expliquer le principe de l’Agent et montrer comment les outils et ReAct aident un modèle à résoudre seul des problèmes inconnus. L’entraînement prend généralement beaucoup de temps. Les connaissances ont donc souvent plusieurs mois de retard, voire six mois.
</JimmyNote>
