# Project rules

## Preserve tutorial source text

- **Do not modify tutorial source text unless the user explicitly requests that change.**
- Treat tutorial titles, prose, examples, code samples, exercises, and translations as protected content. Do not rewrite, polish, correct, shorten, expand, translate, delete, or reorder them without an explicit user instruction.
- Requests to change layout, styling, components, navigation, tooling, or application code do not authorize changes to tutorial text. Preserve the original wording when making these changes.
- If a technical change requires a tutorial text change, explain the required change and obtain explicit user approval before editing the text. If you notice a content issue outside the requested scope, report it without changing it.
- Before completing a task, review your diff and remove any tutorial text changes that the user did not request. Do not revert existing user changes.

## Project documentation

- This project does not use the GEB fractal documentation protocol.
- Do not create or require L1/L2/L3 documentation, directory README maps, or INPUT/OUTPUT/POS/PROTOCOL file headers.
- Keep useful project and task documentation only when it helps development or use.
