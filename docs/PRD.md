### 0.1 已明确的需求

- 建设 AI coding 教程网站，而不是产品 API 文档站。
- 采用接近 Vercel Grid 的结构感，配色偏复古，融入 Macintosh 128K 风格；阅读布局参考对话中的截图。
- 教程在本地使用 Markdown 编写、通过 Git 管理。
- 支持英文、中文、日语、法语和西班牙语，覆盖网站界面和教程内容的国际化能力。
- 保留正文插入选择题、视频 iframe 等互动组件的扩展能力，但等作者实际写文章、出现具体需求后，再开发对应组件，不作为首版前置工作。
- 使用 Fumadocs；参考 Better Auth 的“复用 Fumadocs UI、按需定制”方式，不从零重写整套文档 UI。

## 1. 产品目标与用户

### 1.1 产品定位

一个以文章为主的多语言 AI coding 学习网站，后续按真实内容需要增加互动练习。帮助读者学习描述任务、提供上下文、检查代码与验证结果的完整工作流。

网站不是在线 IDE，也不是带账号、考试和证书的完整教学平台。首版重点是**内容好写、文章好读、语言可选、课程有顺序、进度可继续**。

### 1.2 核心使用场景

| 用户 | 需要完成的事情 | 网站支持 |
| --- | --- | --- |
| 初学者、产品经理、设计师、独立开发者 | 按顺序学习 AI 辅助编程 | 课程结构、前置要求、预计时长、图文步骤 |
| 已使用 AI coding 工具的读者 | 查找具体概念和操作说明 | 当前语言搜索、目录锚点、直达课时 URL |
| 回访读者 | 找到上次位置，了解已学内容 | 本地进度、继续学习、可取消的完成标记 |
| 不同语言的读者 | 使用本语言界面，阅读已有译文 | 语言切换、准确的译文可用性提示、不丢失课时身份 |
| 作者与译者 | 新增原文或译文，不修改页面代码 | 本地 Markdown / MDX、模板、元数据校验和预览 |

### 1.3 首版成功标准

作者能够复制模板、修改内容与必要目录配置，完成校验和发布；不需要每篇文章新增 React 页面，也不需要先开发互动组件。译者能够通过增加语言文件关联同一课时。

读者能够选择五种语言之一，进入当前语言可读的课程，阅读图文代码、使用目录及前后导航、主动标记完成，刷新或切换译文后恢复同一课时的完成状态。

缺失译文不生成假页面、不泄露草稿、不把用户悄悄送到另一种语言。移动端可完成同一流程。测验、视频嵌入和交互式练习不属于首版成功标准。

国际化不包含请求时机器翻译、在线翻译编辑器、翻译外包平台接入、繁体中文、更多地区变体、多域名站点或国家定位。可在站外辅助翻译后人工审核提交，但不把自动生成内容当作已审校译文。

Better Auth 只作为文档架构和 UI 定制参考，不接入其认证或 AI 聊天功能。截图中的下载和赞助区域不自动成为需求。

## 3. 视觉与交互规范

### 3.1 设计原则

**结构现代，质感复古。** 用可见网格、细边框、纸白底色、等宽标签和少量窗口元素建立辨识度，不做可拖动的模拟 Macintosh 桌面。

首页与课程总览强调网格，文章页收敛装饰。正文不铺密集网格、噪点或扫描线，不以闪烁光标、开机或打字机动画阻塞阅读。

Vercel Geist Grid 是视觉参考，实现使用本项目的 CSS / Tailwind 组件，不依赖未经确认可安装的内部 Grid 包。[S1]

### 3.2 颜色 token

| Token | 初始值 | 用途 |
| --- | --- | --- |
| `background` | `#F4F1E8` | 暖纸白背景 |
| `surface` | `#E9E5DA` | 提示和信息面板 |
| `foreground` | `#24231F` | 主要文字、深色按钮 |
| `muted-foreground` | `#6B675E` | 辅助说明、时长、日期 |
| `border` | `#CFC8BA` | 装饰网格、弱分隔线 |
| `border-strong` | `#39372F` | 控件轮廓、选中态 |
| `link` | `#304A91` | 链接、焦点强调 |

这些是设计起点，需实际测试对比度。焦点和必要控件边界不能只用浅色装饰线；状态同时提供文字或图形，不只依赖颜色。

主题变量统一管理，使用 Fumadocs 主题变量或 shadcn 桥接方案，避免多个组件系统各维护一套颜色。[S2]

### 3.3 排版与组件外观

- 中文与日语正文以 17px、约 1.8 行高为起点，移动端不低于 16px；英文、法语和西班牙语按实际长文调整行高。正文最大宽度约 760px。
- 短标签、课程编号和代码使用等宽字体；长正文优先清晰的常规字体。按 `lang` 配置系统中文、日文字体回退，覆盖法语、西班牙语重音字符。不依赖商业字体文件或一次下载全部 CJK 大字库。
- 主要使用直角或最多 2px 圆角，按钮具备 hover、active、disabled、focus-visible 状态。
- 普通区域 1px 边框，必要面板可使用深色边框与简化标题栏，不预建 Quiz / Exercise 外壳。
- 正文链接带下划线；代码块有语言信息与复制按钮，成功或失败反馈均本地化，不虚报复制成功。
- 表格与代码在自身容器横向滚动，不撑宽整页；法语、西语长按钮允许合理换行，日语不按拉丁字符的强制断词处理。

复用 Fumadocs 正文样式，不叠加第二套同名 prose 插件；确需其他排版插件时隔离类名。[S2] 五种语言共享视觉 token，不复制五套页面。

### 3.4 布局与断点

| 视口 | 布局 |
| --- | --- |
| `< 1024px` | 单栏正文，移动课程目录入口，顶部折叠页内目录 |
| `1024–1279px` | 左侧课程目录 + 正文，顶部页内目录 |
| `>= 1280px` | 左侧课程目录 + 正文 + 右侧页内目录 |

整体最大宽度约 1440px，左栏约 248px，右栏约 200px，正文使用 `minmax(0, 1fr)`。间距随可用空间调整，不能固定三栏相加导致溢出。

先检查 Fumadocs 的断点和变量，避免叠加冲突导航。顶栏、锚点偏移和移动工具栏共享尺寸 token。

移动菜单与语言切换菜单均需焦点管理、Escape 关闭、滚动处理及跳转后的合理焦点。交叉线使用 `aria-hidden` 且不拦截指针。全语种检查长标题、200% 缩放和窄屏。

## 4. 信息架构与页面需求

### 4.1 路由与语言入口

所有公开页面均带语言前缀，包括默认中文。使用小写 `en / zh / ja / fr / es`，不使用 `cn` 或 `jp`。除语言前缀外，首版课程、模块、课时沿用稳定的 ASCII slug，不翻译 URL 路径段。

| URL | 页面 | 关键内容 |
| --- | --- | --- |
| `/` | 语言入口 | 临时重定向至选定语言首页，不重复提供无前缀内容 |
| `/[lang]` | 首页 | 当前语言的价值介绍、课程和入口 |
| `/[lang]/courses` | 课程列表 | 当前语言的公开课程或本地化空状态 |
| `/[lang]/courses/[course]` | 课程总览 | 当前语言目标、前置要求、公开课时、本地进度 |
| `/[lang]/courses/[course]/[...lesson]` | 课时页 | 当前语言图文、目录、完成状态、前后导航 |
| `/[lang]/about` | 关于与使用说明 | 网站、本地保存、语言偏好、外部链接说明 |
| `/api/search/[lang]` | 静态搜索数据 | 单一语言的公开索引，与文章同一次构建产生 |

`[lang]` 严格验证白名单。`[...lesson]` 可含模块，例如 `/ja/courses/ai-coding/foundations/first-change`。各语言 `index.mdx` 对应课程总览，不计课时；模块只是分组。

语言解析优先级：明确的 URL 前缀 > 有效的语言偏好 Cookie > 可匹配的 Accept-Language > 默认 `zh`。协商只用于 `/` 等允许的无前缀入口；明确的 `/fr/...` 不因浏览器语言或 Cookie 改跳中文。使用语言偏好而非 IP、国家或地理位置；中文入口明确标注简体中文。

允许的无前缀旧入口 `/courses`、`/courses/...`、`/about` 重定向到选定语言的对应路径；缺失目标按正常 404 处理，不跳另一种语言内容。未知 `/de/...`、任意未知路径返回真实 404，不能被盲目追加成 `/zh/de/...`。无前缀入口用 307，含 Cookie / 请求头协商的响应不进入共享永久缓存。

路由、中间件、语言链接只采用一个统一策略；排除 `/api`、`/_next`、公开素材、robots、sitemap 等，避免图片或搜索索引被语言重定向。内容查询、缓存键和静态参数均包含语言。

### 4.2 首页与课程列表

首页用少量网格说明学什么、如何学、从哪里开始。主要 CTA 进入当前语言第一门公开课程；没有课程时指向本语言课程列表或语言选择，不链接到不存在的课程。

卡片展示本地化标题、简介、难度、当前语言可读课时数和总时长。统计来自内容源，不手写数字，不将原文数量冒充已翻译数量。

全部内容未发布或当前语言尚无译文时，展示本语言空状态，可提供明确标注语言的其他版本入口。不自动展示原文正文或制造空课时。

### 4.3 课程总览

显示本语言学习目标、适合人群、前置要求、模块和课时列表，以及开始 / 继续 / 复习入口。全部来自当前语言 CourseManifest。

进度只统计本语言已发布课时，不含介绍、分组、外链或草稿。译文不齐时写明“本语言已发布 X 课”，不能把本语言 100% 描述为所有语言课程均已学完。

按课程提供重置确认，说明会清除本课程所有语言共享的完成标记和最近位置，不影响其他课程或语言偏好。首版不出现清除测验的文案。

### 4.4 课时页

头部显示本语言课程、模块、标题、简介、时长，以及适用的真实验证日期和工具环境。正文支持 Markdown、代码、图片、表格与实际采用的 Fumadocs 组件，不依赖自定义教学组件。

侧栏显示当前课时和完成状态；页内目录来自本语言正文标题，不能借用原文锚点。底部提供完成 / 取消完成及上一课 / 下一课，导航只在当前语言可读课时中移动。

标记完成后留在本页并反馈；点击下一课不自动标记完成。首尾边界明确，最后一课提供本语言课程总览入口。

### 4.5 语言切换与缺失译文

桌面和手机均提供可见切换入口，使用语言自称：**English、简体中文、日本語、Français、Español**，不使用国旗代替语言。具备本地化可访问名称、当前选择及键盘操作。

同一课时切换语言时，通过稳定的 `courseId + lessonId` 查询目标语言的公开译文，不只替换 URL 字符串。

| 情况 | 行为 |
| --- | --- |
| 目标译文存在并公开 | 打开对应译文，保持共享完成状态 |
| 课时缺译文，但目标语言课程总览已公开 | 切换项明确提示“此课暂无译文，将打开课程总览”，再导航到该总览 |
| 连课程总览也没有 | 切换项提示“该语言暂无此课程”，导航到该语言课程列表 |
| 直接访问缺失或草稿译文 URL | 返回目标语言 404，提供本语言课程列表及实际公开的其他语言版本入口 |
| 首页、课程列表、关于页切换 | 保持页面类型，切换对应语言路径 |

只在目标标题锚点实际存在时保留 hash；否则去掉 hash 并回到文章顶部，不保证跨语言自动定位同一段。跨语言切换清空搜索弹窗中的旧查询和结果，避免旧语言结果残留。

偏好 Cookie 仅保存白名单语言，失效时安全忽略；禁用 Cookie 不影响带前缀 URL 和手动切换。偏好不属于课程进度，不随课程重置清除。不在静态文章渲染时按 Cookie 替换正文语言。

## 5. 内容系统与作者协议

### 5.1 内容组织

使用 Fumadocs MDX 编译本地 Markdown / MDX，Config API 集中维护 collection 和 schema。[S3][S4] 国际化采用**语言目录方式**，即 Fumadocs 的 dir parser 路线，不与语言后缀文件方式混用；具体接入在 M0 锁定版本验证。[S5][S13]

```text
content/
  zh/
    meta.json
    ai-coding/
      index.mdx
      meta.json
      foundations/
        meta.json
        first-change.mdx
        useful-context.md
      workflow/
        meta.json
        verify-results.mdx
  en/
    meta.json
    ai-coding/
      index.mdx
      meta.json
      foundations/
        meta.json
        first-change.mdx
  ja/
    meta.json
  fr/
    meta.json
  es/
    meta.json
messages/
  en.json
  zh.json
  ja.json
  fr.json
  es.json
public/images/courses/
```

目录仅说明职责，不是已存在内容。空语言目录可以没有课程，不能为凑齐结构生成公开占位文章。

`content` 是教学内容唯一扫描根目录；PRD、README、开发文档、字典和测试 fixture 不编译成课程。每种语言的 `.mdx` 也可只写普通 Markdown。同语言同路径不得同时存在 `.md` 与 `.mdx`。

### 5.2 元数据与稳定身份

| 字段 | 适用对象 | 约束 |
| --- | --- | --- |
| `kind` | 全部 | `course` 或 `lesson` |
| `courseId` | 全部 | 逻辑课程稳定 ID，译文沿用，课时必须匹配所属课程 |
| `lessonId` | 课时 | 逻辑课时稳定 ID，所有译文沿用，不由标题或序号生成 |
| `sourceLocale` | 课程 | 原文语言，必须在五语白名单中；各语言课程声明一致，首批默认 `zh` |
| `title` / `description` | 全部 | 当前文件语言的非空标题和描述 |
| `level` | 课程 | `beginner` / `intermediate` / `advanced`，界面翻译标签 |
| `goals` / `audience` / `prerequisites` | 课程 | 本语言目标非空数组、受众非空文字、前置要求非空数组 |
| `durationMinutes` | 课时 | 大于 0 的整数，作者估算，可按译文实际阅读时长调整 |
| `lessonType` | 课时 | `concept` / `tool` / `practice` |
| `lastVerified` | 课时 | 有效日期 YYYY-MM-DD；工具操作课必填 |
| `testedWith` | 课时 | 工具操作课必填，记录实际版本或环境 |
| `contentRevision` | 原文课程介绍和原文课时 | 正整数，原文实质内容更新时增加 |
| `translatedFromRevision` | 对应译文 | 正整数，标明基于哪一版原文审校 |

文件语言从语言目录推导，不重复维护另一个可能冲突的 `locale` frontmatter。`sourceLocale` 从课程继承，不要求每个课时重复声明。

同一逻辑课程可以存在五份语言文件：唯一性检查是 `(lang, courseId)` 和 `(lang, courseId, lessonId)`，不能把正常译文当作重复 ID。不同逻辑课程不得复用 courseId，同课程不同课时不得复用 lessonId。ID 只用小写字母、数字和连字符，不含冒号或路径分隔符。

首版同一课时各译文相对路径一致，使用相同模块与 ASCII slug；校验器检查身份、归属和路径一致性。跨语言关联仍以稳定 ID 为准，不依赖可翻译标题。原文语言由课程 sourceLocale 定义，不因默认站点语言改变。

已发布 URL 变动需要为受影响语言维护重定向。`lastVerified` 是真实验证日期，不随修正错别字、翻译提交或 Git 最后修改时间自动刷新。翻译不得虚构工具验证结果。

### 5.3 顺序与统一内容清单

各层 meta.json 的 pages 使用显式列表，不再增加 frontmatter order，不使用通配符、隐藏项或外链伪装课时。[S5]

```json
{
  "title": "基础概念",
  "pages": ["first-change", "useful-context"]
}
```

课程原文目录定义教学顺序；译文目录只列本语言已有文件，顺序必须是原文顺序的子序列。各语言模块标题本地化，不从中文 meta 静默借用标签。不要求为未翻译课时建立文件或目录项。

构建生成统一内容清单及按语言派生的 `CourseManifest(lang)`，包含课程、模块、公开课时顺序、统计和稳定 ID 到本语言 URL 的映射。另由相同数据派生公开 `TranslationMap`，只包含真实公开的译文身份和地址。

总览、侧栏、前后导航、时长、进度分母、继续学习、搜索和 SEO 使用这些数据，不各维护顺序或翻译数组。缓存必须带 lang；查找课时不能忽略语言后返回遇到的第一份文件。

校验失效目录项、重复 URL / 语言内 ID、错误归属、缺少原文身份、译文错配和未列入目录的课时。每个内容文件在本语言目录中恰好出现一次。

### 5.4 公开范围与原文下架

`content/` 中列入 `meta.json` 的课程和课时都是公开内容。没有单独的审校或草稿状态。某语言完全没有课程是正常空状态，不是构建错误。没有课时的课程版本校验失败；过滤后没有课时的模块不显示。

下架是删除文件，不是切换状态。原文文件缺失但译文仍引用时校验失败。译文不能在原文已删除后继续公开。

公开清单贯穿路由、静态参数、RSC、目录、首页、搜索、sitemap、语言切换、hreflang、统计和前后导航。仅隐藏菜单或 noindex 不等于未发布。直接请求仍须从这份清单查询。

不允许内容源、框架语言 fallback 或缓存把原文补到缺失译文 URL。即使底层有回退能力，公开清单也必须以实际语言文件为依据。缺失译文不得进入可公开请求的数据；public 中的素材始终按公开资源处理，不存密钥。

### 5.5 首版写作示例

以下是课时写作模板，字段与公开课 `content/zh/ai-coding/foundations/first-change.mdx` 相同；所属课程 sourceLocale 为 zh。

````mdx
---
kind: lesson
courseId: ai-coding
lessonId: first-change
title: 用 AI 完成第一次代码修改
description: 描述一个小任务，并检查修改是否符合预期。
durationMinutes: 12
lessonType: practice
contentRevision: 1
---

## 本节目标

完成一次小范围代码修改，并说明你如何验证结果。

## 描述任务

告诉 AI 要修改什么，以及哪些行为必须保持不变。例如：

> 将按钮文字改为“开始学习”，保留原来的点击行为，不修改其他组件。

```tsx
<button onClick={handleStart}>开始学习</button>
```

## 检查结果

查看代码差异，确认改动范围，再运行项目中适用的验证。

## 动手练习

将示例页面中的按钮文字改为“开始学习”。

### 验收标准

- 按钮展示新文字。
- 点击行为没有变化。
- 没有修改与任务无关的文件。

### 参考思路

先定位组件，再限定改动范围，最后检查差异并验证按钮行为。
````

英文译文放在 `content/en/ai-coding/foundations/first-change.mdx`，沿用 courseId、lessonId；将标题、简介和正文翻译，使用 `translatedFromRevision: 1` 代替原文的 contentRevision。日、法、西同理，不新增 React 页面。

代码标识符、命令、路径、API 和配置键不因翻译而擅自改变。示例中的用户可见文字如需本地化，必须同步检查上下文、预期结果与截图。

图片提供本语言 alt；视频先用外链和摘要。不在待发布文章中放未实现的 Quiz、VideoEmbed 或 Exercise；互动需求记录到开发文档，不用公开空组件占位。

### 5.6 作者约束与校验

正文只写内容和已支持组件参数，不写 hooks、回调、网络请求、大段 Tailwind class 或业务实现。组件统一注册，不要求逐篇 import。

首版校验元数据、语言、课程归属、翻译身份、目录、ID / URL、静态内部链接、标题锚点、本地资源与 MDX 可构建性。未知组件应明确失败，不能静默为空；不预开发未来题目的参数解析或判分校验。代码围栏中的 JSX 只是示例，不执行 eval。[S6]

文章内部链接使用包含目标语言的最终站点路径，例如 `/fr/courses/ai-coding/foundations/first-change`；页内使用本文件有效锚点。跨语言链接必须明确标注目标语言。首版不做隐式链接翻译或不明确的相对路径猜测。图片路径不加语言 URL 前缀。

新增译文时检查链接对应版本和锚点，不能只翻正文、保留失效原文链接。CI 校验目标确实存在且公开；外部网络可用性不作为每次构建硬依赖，发布前人工抽查。

Markdown 任务列表只是正文，不等于完成状态；图文练习不需要组件。只编译维护者审核的内容，不接受不可信 MDX 上传，首版不支持裸 iframe 或外部脚本。

### 5.7 UI 字典与框架翻译

网站自有文案使用 next-intl 和本地 messages 字典；Fumadocs 原生控件通过其翻译接口接入同一语言配置。Fumadocs 的 UI 翻译不等于自动翻译整站或教程正文。[S13][S14]

五语范围包括首页、课程列表、难度、时长、导航、搜索、复制反馈、完成 / 取消、重置确认、加载与空状态、存储失败、缺失译文、404、关于说明、页内目录及 aria-label。品牌与明确保留的技术术语不强行翻译。

字典按功能命名空间组织，使用稳定键，不在组件散落三元语言判断。消息包含完整句子，用 ICU 处理插值与复数，不通过拼接数字加英文后缀构造语句。[S17]

CI 比较五语必需键、空字符串、插值参数和 ICU 语法；复数分支允许因语言规则不同而不同。关键文案缺失必须阻止发布，不靠默认英文回退假装完成翻译。上游语言包只作为起点，实际采用的控件逐项验证。

日期、数字、课时与时长使用本语言格式。date-only 的 lastVerified 不因浏览器时区偏移一天；服务端和客户端格式配置一致。服务端只加载当前语言字典，客户端仅接收必要命名空间，不加载全部五语正文和字典。

### 5.8 翻译更新与发布流程

流程为：创建 / 更新原文 → 确认稳定身份与原文 revision → 新建译文草稿 → 翻译正文和元数据 → 校验目录、代码、链接、图片说明 → 人工审校 → 单独将该译文发布。

原文实质内容变化时增加 contentRevision；译文审校后更新 translatedFromRevision。后者不能大于当前原文版本。仅改错别字不强制增加原文 revision。

译文版本落后时生成作者待审报告，并在已公开译文显示本语言“译文尚未同步最新原文”提示及实际原文入口；不自动覆盖内容，也不因原文小更新直接撤下全部译文。作者可将不再适用的译文设为草稿。更新提示不得虚报已完成重新验证。

首版只需文件字段、校验报告和必要提示，不建设翻译管理后台、自动翻译队列或翻译人员权限系统。技术验证用五语 fixture；正式未就绪译文维持草稿或缺失状态。

## 6. 正文互动组件：后续按写作需求开发

本节不是首版实施要求，不冻结组件 API，也不先开发通用教学组件库。v0.1 的 Quiz / VideoEmbed / Exercise 详细协议不再是当前基线。

### 6.1 启动条件与工作方式

作者写真实文章后，判断正文、代码、图片、外链或现有 Fumadocs 组件是否足够。只有明确需要学习交互时，启动对应 T 任务。

每次提供具体文章、实际题目 / 视频 / 练习、读者操作、预期反馈、使用语言，以及是否确需保存状态，再补充参数、状态、边界和验收。

文章只需要视频就只开发所选平台的视频组件；开始第一篇文章不代表整套组件库开工。组件未开发前，图文或外链可继续发布。

### 6.2 候选组件

| 候选 | 届时确定 | 尚未开发时 |
| --- | --- | --- |
| Quiz | 单 / 多选、提交、解释、重试、保存需求和必要版本协议 | 文字问题与参考解释 |
| VideoEmbed | 平台、地址、点击加载、尺寸、原站入口、权限和封面 | 视频外链与摘要 |
| Exercise / Hint / Solution | 展开提示、参考方案、分步展示和状态 | Markdown 任务及验收标准 |
| PromptCompare | 比较内容、揭示方式、切换和差异标注 | 标题、引用、代码或表格 |

名称是候选，不据此生成空文件、占位导出或首版模板引用。

### 6.3 启动后的质量边界

统一视觉 token，键盘操作、必要反馈、移动端、无 JavaScript 降级与局部客户端边界；不破坏默认 MDX 渲染。控件 UI 继承五语字典，题干、提示和解释属于文章译文；不要求所有语言文章都用同一组件。

测验只是自测，不增加考试、证书或解锁门槛。有作答保存需求时，再明确不同语言题目是否语义等价、可否共享状态、题目版本和重置规则；不能直接把共享课时进度规则套到翻译可能不同的答案上。

视频实际接入时再配置来源白名单、可信 URL、iframe 权限、CSP 和隐私说明；考虑点击加载及原站入口。iframe load 不等于成功播放，不承诺自动捕获所有跨域故障。[S7]

参数校验、隐藏答案搜索、折叠内容目录、状态和测试随组件开发，不以预留能力放回 P0。发布所选组件时执行第 14.1 节适用验收。

## 7. 学习记录与状态一致性

本节只管理课时完成和最近位置，与延期的正文教学组件解耦。

### 7.1 完成状态与继续学习

只有主动点击完成按钮才更新；进入、滚到底、切换译文或点击外链都不自动完成。

**同一 courseId + lessonId 的五语译文共享完成标记，界面进度按当前语言公开课时计算。** 当前语言未翻译、已删除或草稿课时不计入该语言分子分母；原记录可保留，不因此删除其他语言进度。

继续学习只在当前语言清单中选目标：

1. 没有有效记录，进入该语言第一篇公开课时。
2. 最近访问的逻辑课时在当前语言仍公开且未完成，进入它的当前语言 URL。
3. 否则进入当前语言顺序中的第一篇未完成课时。
4. 当前语言公开课时全部完成，显示复习入口并进入第一篇；注明仅代表本语言已发布部分。

当前语言零课时时，不计算 0/0 或显示全部完成，展示可理解空状态。进入课时更新最近位置，只存稳定 lessonId，不保存精确滚动坐标或带旧语言的 URL。

### 7.2 存储协议

本地存储按 origin 隔离，可能受限或被清除，不是云同步。[S8] 进度区域用当前语言说明保存在此浏览器；换域名不会自动迁移。

```text
lac:v1:<courseId>:lesson:<lessonId>
  -> { completed: boolean, updatedAt: ISODateString }

lac:v1:<courseId>:last
  -> { lessonId: string, visitedAt: ISODateString }
```

键故意不包含 lang，避免译文重复算一课；切换语言不创建五份完成记录。语言偏好单独放 Cookie，不混入课程命名空间。

不定义 quiz / exercise 条目或作答恢复接口。持久化封装在独立模块，组件不散落直接操作 localStorage。展示和继续目标通过当前语言的有效 manifest 解析。

### 7.3 异常与多标签页

读取、JSON 解析、写入均处理错误；存储禁用、损坏或写失败时降级为页面会话内存，显示本语言“本次学习记录可能无法保存”，正文与导航不受影响。

未知结构不按成功展示，也不在初始化时悄悄覆写。禁止 localStorage.clear()。

SSR 与首次客户端渲染使用一致待恢复状态，读取前不写默认值，避免覆盖真实进度或 hydration 错误。进度不把整篇文章变成客户端组件。

监听 storage 事件及重新聚焦时重读，跨语言标签页也应同步完成状态；接收变化不回写，避免循环。同一条目冲突采用最后成功写入，不宣称事务性协同。不同语言窗口各自保持 URL 语言，不因其他窗口改变偏好 Cookie 而跳转。

### 7.4 取消与重置

取消完成改变共享课时标记，不清除最近位置，也会反映到其他语言同一课时。

重置需要确认，只清除当前课程所有语言共享的记录及旧课时残留，不影响其他课程或语言偏好。文案明确这一范围。取消无副作用，成功有反馈并同步其他标签页。

## 8. 搜索需求

采用 Fumadocs 静态搜索模式，构建导出与客户端查询方式配套，不混用动态查询接口。[S9] 首版搜索只查当前语言已发布内容，不承诺跨语言翻译检索。

`/api/search/[lang]` 按白名单生成该语言索引，首次打开搜索才加载。索引和缓存键包含语言及内容构建版本，不能下载全部五语后仅在 UI 隐藏其他结果。未知语言返回 404，没有内容的有效语言返回空索引而非默认语言索引。

底层具体索引导出 API 需在 M0 验证；即使框架支持共享多语数据库，本项目也要求每个公开静态端点只导出本语言数据。建索引与查询分词配置必须匹配，不能混用不同版本的客户端与服务端方案。

覆盖标题、简介、正文和小标题，结果显示本语言课程归属与命中位置。切换语言清空旧查询、旧选中和结果；异步响应不能回填到新语言，失败允许重试。

不承诺索引 JSX 属性或任意表达式；关键知识放在普通正文。未来隐藏答案规则随对应组件开发，不预做题目索引平台。

支持 Cmd/Ctrl+K、移动入口、中文和日语输入法组合输入；composition 期间 Enter 不误选结果。空查询、无结果、加载、失败、重试、读屏标签全部翻译。高亮使用安全结构化渲染。

| 语言 | 代表性测试词 |
| --- | --- |
| en | context、verify code、prompt |
| zh | 上下文、检查代码、AI coding |
| ja | コンテキスト、コードの確認、プロンプト |
| fr | contexte、vérifier、verifier |
| es | contexto、código、codigo |

用与 fixture / 真实文章对应的词验证预期页面出现在前五条。中文、日语测试不带空格的查询；法语、西语验证约定的带 / 不带重音词均能找到样例。英文技术术语可以匹配当前语言正文，但不能借用其他语言结果凑命中。

全部 URL 和锚点实际有效。框架文档说明的多语言能力不是本站测试结果；五语检索与索引体积须实测。[S9]

## 9. 技术方案与工程结构

### 9.1 技术选型

| 层 | 方案 | 约束 |
| --- | --- | --- |
| 应用 | Next.js App Router + React + TypeScript | 兼容稳定版本，不使用 canary |
| 内容 | Fumadocs MDX + Core | 本地 collection、schema、页面树、搜索，封装语言适配 |
| 文档 UI | Fumadocs UI | 优先复用，再局部替换 |
| 国际化 | next-intl + Fumadocs i18n 接口 | 一个 locale 配置源、一个路由策略；不叠加双重中间件 |
| 样式 | Tailwind CSS v4 + 统一 token | 自定义网格和复古面板 |
| 基础控件 | Radix UI 按需 | 共用主题与本地化文案 |
| 校验 | schema + Markdown / MDX / 字典检查 | 不运行不可信内容，不预建教学参数平台 |
| 测试 | Vitest + Playwright / Axe | 单元、组件、生产构建 E2E，包含五语 fixture |
| 包管理 | pnpm | 固定 packageManager，提交 lockfile |
| 发布 | Vercel + GitHub Actions | CI、预览、生产分开 |

M0 记录 Node、pnpm、Next.js、React、next-intl 和 Fumadocs 三个包的实际版本与安装 / 构建结果。不要照搬 Better Auth 历史依赖或假设三个 Fumadocs 包主版本一致。

Fumadocs 官方支持与其他国际化库组合，但其本身不是整站全文翻译系统。[S13] next-intl 负责应用字典和语言路由，Fumadocs 获得相同 lang 及 UI 翻译；共享 locale 配置生成两侧适配，禁止手写两份语言清单。

### 9.2 Fumadocs 定制与国际化接入

参考 Better Auth 保留 DocsLayout 与正文组件、局部替换侧栏的方式。[S10] 顺序为：主题变量 → 参数与插槽 → 包装组件 → 必要区域替换。

优先复用正文、目录、代码、移动交互；侧栏可以定制 item 时复用，否则局部替换，但不直接修改 node_modules 或大面积依赖内部 DOM。[S11]

所有页面布局、内容查询、页面树、搜索和 RootProvider 获得同一个有效 lang。Fumadocs 默认控件的文字与应用 messages 分工明确，不出现应用切换成功但搜索和目录仍是英文的半套国际化。[S14]

next-intl 使用始终带语言前缀的策略，与 Fumadocs 的前缀选项一致。默认自动生成的全语种 alternate links 应关闭；本项目根据真实 TranslationMap 生成，避免指向缺失译文。[S16]

具体 Proxy / middleware 文件命名、dir parser、Provider 与静态参数 API 随锁定版本验证并记录，不同时照抄两套互相冲突的教程。

### 9.3 服务端与客户端边界

正文、字典、metadata、目录和文章路由优先服务端渲染 / 静态生成。进度、搜索、语言菜单与必要导航使用局部 Client Component；未来教学组件不提前建专用 Provider。[S12][S15]

带语言前缀的文章只按路径 lang 选择正文，不在渲染时读取 Cookie 决定内容，避免缓存串语言。语言入口协商与静态文章分离。

不从客户端 import 全内容源、文件系统或全部 MDX。只传必要的序列化课程摘要、当前课时、公开可用语言和该语言所需字典。生产不请求 GitHub API 或远程抓取 Markdown。

## 10. 非功能需求

### 10.1 性能与体验

正文不等待进度或搜索索引才显示；不将全部正文、全部语言字典打入共享客户端入口。索引按语言和需求加载。

图片声明尺寸或比例，优先本地优化。首版不加载第三方播放器或缩略图；视频文件不入 Git。字体有系统回退，不能阻塞阅读。

首页、课程总览、代表课时的固定环境移动 Lighthouse 性能目标 >= 90，取三次中位数并记录环境；至少覆盖原文与一种非拉丁译文页面。每语言搜索索引压缩体积目标 <= 500 KB，超出先分析内容与分包，不直接引入付费服务。记录实际下载语言，避免全量五语隐藏开销。

未来视频或测验单独检查脚本开销、布局稳定性和按需加载，不提前添加资源。

### 10.2 可访问性

项目验收要求：普通文字对比度 >= 4.5:1，大字 >= 3:1，必要控件轮廓和焦点 >= 3:1；装饰网格不承担识别职责。

页面唯一主标题、合理标题层级、主要区域语义、跳转正文入口；图片 alt、控件可访问名称使用本语言。html lang 映射为 en、zh-Hans、ja、fr、es，混用其他语言的引用可标注局部 lang。

搜索、语言选择、目录、完成按钮、实际采用的组件和重置可只用键盘操作。尊重 prefers-reduced-motion；320px、200% 缩放、中日长标题及法西长文案不丢功能。

无 JavaScript 时仍可阅读和使用普通语言 / 文章链接；依赖 JS 的控件有本地化说明，不伪装可用。后续教学专用可访问性随组件补充。

### 10.3 安全与隐私

仅编译审核内容，不接受用户代码或 MDX。不支持裸 iframe、外部脚本和任意嵌入，不为未来视频预放宽 CSP。

语言参数、偏好 Cookie、动态字典加载和文件路径都经过白名单，不能拼出任意文件路径或外部重定向。API 和静态资源不被错误语言路由拦截。

不采集姓名、邮箱、Key 或代码，不发送本地进度到服务端，不默认接分析脚本。关于页五语说明本地保存、功能性语言偏好 Cookie 与外链边界；不声称托管平台也没有访问日志。未来播放器实际接入时再更新隐私说明。

### 10.4 多语言 SEO 与公开范围

每个公开语言版本有本语言 title、description、分享信息和指向自身的 canonical。不能把五语 canonical 全指到中文。[S18]

根据真实存在的译文生成 hreflang，包含当前版本及对等版本并双向一致，使用 en、zh-Hans、ja、fr、es。缺失或已删除的版本不生成链接。不能依赖框架默认把五个前缀都列为存在；HTTP Link 与 HTML head 不能互相矛盾。[S16][S18]

首页的 x-default 指向语言协商入口 `/`；课程与课时仅在原文公开时可将 x-default 指向该逻辑内容的原文，不把所有课时的 x-default 都指到首页。sitemap 列出所有实际公开的语言 URL，不包含重定向、404 或占位译文。使用同一清单生成 metadata 与 sitemap，不维护重复映射。

正式域名单一配置，生产缺失或非法时构建失败。预览 noindex 不等于访问控制；错误语言、缺失译文和未知路径返回真实 404。404 不输出伪造的 canonical / hreflang 文章信息。

上线前移除脚手架、假作者、虚构课程数量和未完成的 UI 翻译。重定向映射不得成环，目标必须存在且公开。

## 11. 工程质量与发布流程

### 11.1 已实现命令

以下命令已实现。

```bash
pnpm dev               # 本地五语预览
pnpm lint              # 代码和格式检查
pnpm typecheck         # 含必要的内容类型生成
pnpm content:check     # 五语内容、身份、目录、链接、资源和 MDX 校验
pnpm i18n:check        # 五语字典、ICU、翻译对应与待更新报告
pnpm test              # 单元 / 组件测试，CI 非 watch
pnpm test:e2e          # 生产构建关键流程，包含国际化
pnpm build             # 内容与国际化校验后构建
pnpm check             # lint + typecheck + content:check + i18n:check + test
```

UI 缺键、非法引用、译文身份错误是失败；正常缺失译文及允许公开的过期翻译是报告项，不因尚未翻译完整课程阻止构建。

干净环境必须能从 lockfile 安装和生成内容，不依赖残留 .source / .next。Vercel build 同样执行校验，不能只在本地检查。

### 11.2 CI、部署和回滚

PR 执行锁定安装、内容生成、静态与字典检查、单元测试、生产构建和 E2E；用五语 fixture 验证工程，不要求第三方视频、模型、在线翻译或未开发组件可用。

Vercel 预览不改变草稿规则。生产域名、默认语言、语言偏好策略及环境说明写入 README / .env.example，不提交密钥。

预览成功不等于 CI 全通过，也不假设已有权限修改分支保护。通过检查后才提升为生产，保留上一可用部署。

发布后检查五语首页、原文、实际已发布译文、语言切换、搜索和进度；没有译文的语言检查空状态。回滚不清空共享进度；后续存储变更考虑旧应用忽略未知格式。

## 12. 示范课程与内容交付

首发至少一门课程、三个完整原文课时；首批原文默认简体中文，最终由作者确认。五语界面及内容发布能力必须可用，但不要求三个课时全部翻译为五种语言后才允许发布。

| 建议课时 | 核心目标 | 验证能力 |
| --- | --- | --- |
| 第一次小范围代码修改 | 把模糊想法变成具体目标 | 图文、代码、检查步骤 |
| 提供有用的上下文 | 相关代码、约束与验收标准 | 正文、提示、表格或步骤 |
| 检查与验证结果 | 检查差异、运行验证、处理失败 | 文字练习、验收标准、参考思路 |

工程阶段准备一个逻辑课时的五语非公开 fixture，验证同一 ID 的切换、目录、搜索、字体、缺译文、草稿和不同翻译覆盖数量；fixture 不能作为正式课程发布。

正式 UI 五语文案需要审校；教程译文逐篇人工审核发布。尚未准备译文的语言保持空状态，不发布复制原文的假译文。正式内容至少一篇覆盖主要图文排版，不要求视频、Quiz 或 Exercise。

“完整”指学习目标、实质内容及可理解步骤 / 解释，不指组件数量。实际工具操作需验证，不编造日期或环境。需要互动时按 T 系列记录，视频素材届时确认。

| UI 定制变成重写框架 | 优先变量和插槽，必要区域局部替换，升级回归 |
| 双重国际化路由冲突 | 单一配置、单一协商策略，Fumadocs 与 next-intl 适配统一 |
| 默认语言 fallback 冒充译文 | 原始语言文件白名单、公开 manifest、404 和构建输出检查 |
| 译文被当重复内容或错误关联 | 语言内唯一键、稳定逻辑 ID、原文关系和路径校验 |
| 多语言缓存、搜索或导航串内容 | cache key 带 lang，按语言索引，切换取消旧结果，全链路测试 |
| 译文过期或误报重新验证 | revision 来源、待审报告、读者提示，lastVerified 独立维护 |
| 翻译未齐阻止持续写作 | 五语 UI 与逐篇译文分开验收，诚实空状态，不做假译文 |
| 草稿或原文下架内容泄露 | 路由、RSC、索引、hreflang、切换菜单统一过滤 |
| 进度在不同语言含义混乱 | 同逻辑课时共享标记，当前语言分母，重置明确全课程 |
| localStorage 被清除或失败 | 本地边界、提示与内存降级，不承诺云恢复 |
| 国际化扩大为翻译平台 | 仅本地字典和 MDX，不做后台、在线翻译或翻译权限 |
| 提前开发教学组件 | 文章触发，T 不阻塞 P0，无占位、无通用作答平台 |
| 后续视频在读者网络不可达 | 实际接入时点击加载、图文步骤和原站入口 |

M0 无需等品牌、域名、真实文章、全部译文或互动组件设计。公开发布前确认品牌与域名、作者、首门课程及三个原文课时、五语 UI 文案和实际译文覆盖。

默认中文按简体处理，默认入口语言沿用 zh；这两项仍可由产品负责人调整，但不能据此推迟五语架构。视频和互动需求仅在对应 T 任务启动时确认。未经要求不创建账号、购买服务或扩展付费平台。
