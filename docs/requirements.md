## Routes and publication

| Route | Required behavior |
| --- | --- |
| `/` | Detect saved/browser language. Serve English at this URL, or redirect to another language with a private, non-cacheable 307 response. |
| `/` or `/{lang}` | Show the current language's courses. The start-learning action (马上学习 in Chinese) opens LLM 101's first published lesson. Keep a useful empty state when no courses exist. |
| `/courses/{course}` or `/{lang}/courses/{course}` | Render course metadata, available modules, and the syllabus. |
| `/courses/{course}/{lesson}` or `/{lang}/courses/{course}/{lesson}` | Render a published lesson, its local headings, recent-visit recording, inline achievements where authored, and adjacent lessons. |
| `/blog` or `/{lang}/blog` | Render the published blog overview and article directory. |
| `/blog/{article}` or `/{lang}/blog/{article}` | Render a published blog article. Former blog URLs under `/courses/blog` redirect permanently. |
| `/about` or `/{lang}/about` | Explain the site, language preference, and local learning storage. |
| `/api/search/{lang}` | Serve the same build's public, single-language content index. |

Supported languages are `en`, `zh`, `ja`, `fr`, and `es`. English public URLs have no locale prefix; the other four languages retain theirs. Only `/` uses a valid preference cookie, then `Accept-Language`, then `en`. An explicit `?lang=en` homepage choice supports native language links without JavaScript and saves the preference. Other canonical URLs always use their declared language. Former `/en` paths redirect permanently to the equivalent prefix-free URL. Unknown routes and missing translations return HTTP 404 with working recovery links. All 404 entries use the same two-column page with a direct localized Page not found title, regular-weight Geist Pixel title/numeral typography with CJK fallbacks, and square raised recovery buttons. Runtime failures inside language routes use that same complete 404 interface, including the header, footer, course/home actions, and language links. They keep their actual error semantics; displaying 404 does not turn a runtime failure into an HTTP 404 response. Recovery links reload their destination to clear failed client state. There is no separate page-loading-error screen or retry action. `/courses` and `/{lang}/courses` are not pages; the language homepage lists courses.

Content in `content/` is public. Every course and module declares order through `meta.json`. Course introductions do not count as lessons. Course overviews use frontmatter and the generated syllabus; their MDX bodies are not rendered. Lesson URLs omit module directories. Course overview start and syllabus links open lessons in the current tab.
