# Learning AI Coding

一个以本地 Markdown / MDX 内容为核心的 AI coding 教程网站，后续根据实际文章需要逐步增加互动组件。

视觉方向：**Vercel 式可见网格 + Macintosh 128K 灵感的复古阅读界面**。技术方向：**Next.js + Fumadocs MDX / Core / UI + Tailwind CSS**，优先复用文档基础能力，按需定制课程布局。

## 项目状态

当前处于需求规划阶段，尚未初始化应用或实现网站功能。本仓库中的开发命令、工程目录和组件 API 以需求文档中的计划为准，不代表已经可运行。

当前开发顺序：**先完成站点与写作流程 → 作者开始编写真实文章 → 根据具体文章需求逐个开发互动组件**。不需要先开发选择题或播放器才能写文章、验收阅读页或发布首版。

## 首版方向

本地写作、Git 管理、无需登录阅读；支持课程总览、章节导航、图文和代码排版、站内搜索，以及当前浏览器内的课时完成标记和最近学习位置。

保留 MDX 渲染与统一组件注册入口，但**暂不开发 Quiz、VideoEmbed、Exercise / Hint / Solution、PromptCompare 等自定义教学组件**，也不预建其参数校验、作答存储或视频平台适配器。需要引用视频时先用普通外链；练习可以先写成 Markdown 任务与验收标准。没有互动组件的完整图文课程可以正常发布。

站点搜索、移动导航、代码复制和本地课时进度不属于本次延期范围。首版不包含认证、支付、数据库、在线代码执行或 AI 助教。正式名称、域名和首批课程内容需要在公开发布前确认；互动形式及视频平台等到真实写作需求出现后再决定。
