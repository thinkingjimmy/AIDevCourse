# Learning AI Coding

一个以本地 Markdown / MDX 内容为核心、结合互动练习的 AI coding 教程网站。

视觉方向：**Vercel 式可见网格 + Macintosh 128K 灵感的复古阅读界面**。技术方向：**Next.js + Fumadocs MDX / Core / UI + Tailwind CSS**，优先复用文档基础能力，按需定制课程布局和教学组件。

## 项目状态

当前处于需求规划阶段，尚未初始化应用或实现网站功能。本仓库中的开发命令、工程目录和组件 API 以需求文档中的计划为准，不代表已经可运行。

## 首版方向

本地写作、Git 管理、无需登录阅读；支持课程总览、章节导航、单选题、视频嵌入、实操提示、站内搜索，以及当前浏览器内的学习进度。

首版不包含认证、支付、数据库、在线代码执行或 AI 助教。正式名称、域名和首批课程内容需要在公开发布前确认。
